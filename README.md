# HosBank

HosBank est une application web bancaire permettant aux clients de gérer leurs comptes, consulter leurs soldes et leurs historiques, effectuer des virements et gérer différentes demandes bancaires.

## Fonctionnalités

### Client
- Authentification et vérification de l'email
- Consultation des comptes et soldes
- Consultation de l'historique des opérations
- Virements
- Gestion des bénéficiaires
- Demande de compte épargne
- Demande de RIB
- Demande de carte virtuelle
- Opposition de carte
- Demande de renouvellement du PIN
- Réclamations
- Gestion des informations personnelles

### Chargé Client
- Consultation des clients assignés
- Traitement des demandes
- Traitement des réclamations
- Gestion des cartes et des demandes de PIN
- Consultation de l'historique des interactions

### Administrateur
- Gestion des utilisateurs
- Gestion des rôles
- Attribution des clients aux Chargés Client
- Gestion des comptes et des cartes
- Supervision des opérations
- Consultation des statistiques

## Technologies

- Node.js
- Express.js
- PostgreSQL
- EJS
- HTML5
- CSS3
- JavaScript
- Bootstrap / Tailwind CSS

## Architecture

Le projet suit une architecture en trois couches :

- **UI** : interface utilisateur
- **Business** : logique métier
- **Persistence** : accès aux données
